# Frosty Windows

Frosty Windows tells you the night before whether you'll need to scrape frost off your
car before your morning commute, and how much extra time to allow.

This repository only hosts the Android app's downloads. The source code is kept separately.

## Download

Get the newest version from the [Releases page](../../releases/latest), or directly:

**[frosty-windows.apk](https://github.com/user-8472/Frosty-Windows-releases/releases/latest/download/frosty-windows.apk)**

To install it, open the downloaded file on your Android phone. If Android asks, allow your
browser (or file manager) to install unknown apps. Newer versions install over the old one
and keep your locations and settings.
