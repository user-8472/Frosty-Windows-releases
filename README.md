# Frosty Windows

Frosty Windows tells you the night before whether you'll need to scrape frost off your car in the
morning, and wakes you early enough to clear it before you leave. It's free, with no ads, no account
and no tracking.

> **Android phones only.** There's no iPhone version.
>
> Frosty Windows isn't in the Google Play Store yet, so installing it takes a few extra taps compared
> with a Play Store app. It takes about two minutes; the steps are below.

## Install it

Do these steps **on your Android phone** (not on a computer).

1. Tap **[Download Frosty Windows](https://github.com/user-8472/Frosty-Windows-releases/releases/latest/download/frosty-windows.apk)**.
2. Your browser may warn that the file **might be harmful**. That's shown for any app that doesn't come
   from the Play Store. Tap **Download anyway**.
3. When the download finishes, tap **Open**. (Missed it? Open the **Files** or **My Files** app, go to
   **Downloads**, and tap **frosty-windows.apk**.)
4. If you see **"For your security, your phone isn't allowed to install unknown apps from this
   source"**: tap **Settings**, switch on **Allow from this source**, then tap the back arrow.
5. Tap **Install**.
6. **Google Play Protect** may stop you with a message such as "Unsafe app blocked" or "Send app for
   scanning?". It says this because it hasn't seen Frosty Windows in the Play Store. Tap
   **More details**, then **Install anyway**, or tap **Scan app** and then **Install**.
7. Tap **Open**.

### Samsung phones: Auto Blocker

Newer Samsung phones have **Auto Blocker**, which blocks every app that isn't from the Play Store or
the Galaxy Store. If the install is blocked and the message mentions Auto Blocker:

1. Open **Settings** → **Security and privacy** → **Auto Blocker**, and switch it **off**.
2. Install Frosty Windows (the steps above).
3. You can switch Auto Blocker back on afterwards. If a later update is blocked, switch it off again
   while the update installs.

## Set it up

The first time it opens, Frosty Windows walks you through setting up an alert: where the car is parked
overnight, what time you leave, and on which days. Then it asks for a few permissions so it can warn
you on time:

- **Notifications**: to show frost warnings at all.
- **Alarms & reminders**: so warnings and alarms come at the right minute, not a few minutes late.
- **Full-screen alarms** (only if you choose an alarm): so the alarm can fill the screen over the lock
  screen, like the Clock app's alarms.
- **Battery: Unrestricted**: so Android doesn't stop the overnight forecast check that decides whether
  you need to get up earlier.

If any of these are still off, the app's home screen shows a card with a button to fix it.

## Updates

Frosty Windows checks for new versions by itself (**⋮ menu → Settings → Updates**). Updates install
over the old version and keep your alerts and settings.

- The first time it updates, Android may ask whether Frosty Windows may **install apps**. Switch on
  **Allow from this source** and go back.
- Play Protect may ask to scan each new version. Tap **Scan app** or **Install anyway** as above.

## If something goes wrong

- **"App not installed"**: an older copy that was installed a different way is in the way. Uninstall
  Frosty Windows (press and hold its icon → **Uninstall**), then install it again. You'll need to set
  up your alerts again.
- **Can't find the downloaded file**: open the **Files** (or **My Files**) app → **Downloads**, or in
  Chrome tap **⋮** → **Downloads**.
- **Opened this page on a computer**: send yourself the link and open it on your phone instead.
- **The alarm didn't ring**: open the app and check the home screen for a card about permissions or
  battery. Then open an alert, tap **Edit**, and use the test alarm button to hear it.

## Privacy

No ads, no account and no tracking. Your alerts and settings stay on your phone. The app only goes
online to:

- fetch forecasts for the places you set alerts for, from Open-Meteo (and the US National Weather
  Service for US locations);
- look up a place name you search for (Open-Meteo), or, if you tap **Use my location**, ask your
  phone's built-in address lookup (usually Google's) for the name of that spot;
- check GitHub for new versions of the app.
